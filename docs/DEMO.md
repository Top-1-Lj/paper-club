# 使用演示

通过一篇预置论文体验“阅读—记录—讨论—导出”的完整流程，约需三分钟。

## 准备

按 [README](../README.md) 启动应用，并执行 `seed_demo` 和 `import_papers`。准备两个独立浏览器会话，分别登录 `lin` 和 `chen`，初始密码均为 `PaperClub2026!`。已有账号修改过密码时，使用修改后的密码。

## 1. 浏览论文

在论文广场查看本期共读论文，尝试按标题、作者或标签搜索。打开一篇论文，查看摘要、正式发表年份、DOI、原文链接和已有卡片。

对附带导读的论文，打开“带原文依据的阅读卡片”，展开“来源与核对说明”。导读包含六个结构化字段，关键结论可定位到对应 PDF 页码、章节或图表；未知信息和原文差异有单独说明。

## 2. 写下自己的理解

以 `lin` 登录，选择一篇导读论文，创建自己的卡片；已经创建过卡片时，继续编辑原卡片。

依次填写研究问题、核心方法、主要结果、局限、个人理解和待讨论问题，再设置阅读状态。原文中的结论与个人推断宜分别表述，实验数字附上相应条件和原文位置。

需要补充论文时，可通过“录入论文”手动填写元数据和来源链接。DOI、代码链接可留空。

## 3. 进行共读讨论

在另一会话以 `chen` 打开该卡片，发表评论或提出问题。`chen` 可以参与讨论，但不能编辑 `lin` 的卡片；两人的阅读状态各自保存。

返回“我的阅读卡片”，尝试关键词和阅读状态筛选。

## 4. 导出与继续阅读

在卡片详情下载 Markdown，在论文详情下载 BibTeX。导读卡片的 Markdown 会保留来源说明与核对信息。

停止并重新启动应用后，论文、卡片、评论和阅读状态仍保存在原数据库中，可以继续之前的阅读。
